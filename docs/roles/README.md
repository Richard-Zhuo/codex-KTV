# 协作角色

只有任务确实存在对应职责时才启用角色；普通小任务直接按 `AGENTS.md` 执行。

- [PROJECT_CONTROLLER](./PROJECT_CONTROLLER.md)：多任务总控、依赖与资源协调、证据汇总和阶段收口；正式总控保持唯一。
- [MODULE_OWNER](./MODULE_OWNER.md)：模块需求澄清、行为用例、边界说明与效果验收。
- [TASK_START_PROMPTS](./TASK_START_PROMPTS.md)：实现、审核、运行验证、文档和总控的短启动模板。

实现、独立代码审核和运行验证按任务风险分开交付证据，不为每个小修改机械增加角色层级。
