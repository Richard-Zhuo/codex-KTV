# 历史记录

> 本目录保存已结束阶段、被替代入口和过去的验证证据。内容按记录日期解释，**不是当前执行指令**，也不能自动证明后续版本仍通过。

当前任务应从 [文档导航](../README.md) 和 [当前阶段](../CURRENT_STAGE.md) 开始。

## 索引

- [2026-09-27 交付快照](./2026-09-27-delivery/README.md)：文档体系重组前的项目现状、规则、架构、复现和风险说明。
- [2026-09-27 验证记录](./2026-09-27-validation.md)：当时记录的自动测试、浏览器操作和未验收范围。

## 使用规则

- 历史结果必须同时引用日期、适用版本或提交；不能改写成当前会话已执行。
- 历史需求与当前 [REQUIREMENTS](../REQUIREMENTS.md) 冲突时，以当前需求为执行依据，并保留历史差异。
- 历史命令与当前 [DEVELOPMENT_ENVIRONMENT](../DEVELOPMENT_ENVIRONMENT.md) 冲突时，以当前环境文档和实际配置为准。
- 新阶段结束后只归档必要结论和证据索引，不保存重复的当前规则副本。
