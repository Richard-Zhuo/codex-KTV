# 复现运行与验收

## 环境要求

- Windows PowerShell。
- Node.js 可用；当前 Codex 环境中的 Node 可能来自内置运行时。
- 项目没有生产依赖，不需要先安装依赖。
- 若 `npm` 不在 `PATH`，使用已验证命令 `pnpm --package=npm dlx npm test`。

## 1. 确认仓库状态

```powershell
Set-Location D:\iwen-codex\codex-KTV
git status -sb
git remote -v
git log -5 --oneline
node --version
```

预期：分支为 `main`，远端为 `https://github.com/Richard-Zhuo/codex-KTV.git`。如果工作区已有未提交修改，先查看并保留，不要覆盖。

## 2. 运行自动测试

首选：

```powershell
npm test
```

当前环境的已验证替代命令：

```powershell
pnpm --package=npm dlx npm test
```

预期结果：58 项通过、0 项失败。修改 JavaScript 后必须重新运行完整 `npm test`。

需要快速诊断语法时可以额外执行：

```powershell
node --check app.js
node --check rules.js
node --check server.js
```

语法检查不能替代 `npm test`。

## 3. 启动服务

前台启动，最适合观察错误：

```powershell
node server.js
```

需要在本地后台运行时：

```powershell
Start-Process -FilePath node `
  -ArgumentList 'server.js' `
  -WorkingDirectory 'D:\iwen-codex\codex-KTV' `
  -WindowStyle Hidden
```

服务监听 `0.0.0.0:4173`。Codex 任务结束、电脑重启或进程退出后需要重新启动。

## 4. 验证静态入口

```powershell
$staff = Invoke-WebRequest -UseBasicParsing http://localhost:4173/
$admin = Invoke-WebRequest -UseBasicParsing http://localhost:4173/admin
$staff.StatusCode
$admin.StatusCode
```

两项都应为 200。

浏览器检查：

1. 打开 `http://localhost:4173/`，确认横幅为“店员系统”，底部没有“管理”。
2. 使用管理员身份，点击右上角“后台管理”。
3. 确认地址为 `/admin`，横幅为“后台管理系统”，底部只有管理和报表。
4. 打开卓老板的权限编辑，确认“允许审核本人申请”存在且默认未选中。
5. 返回店员系统，确认房间、存取酒、报表、我的仍可进入。

## 5. 核心业务冒烟检查

建议使用“恢复演示数据”后验证，避免旧状态干扰：

1. 以可开房身份打开空房，确认渠道、套餐和应收金额。
2. 增加一笔多商品酒水，再分别使用“收钱”和“结账”，确认房间只有结账后转待清洁。
3. 创建未来预订，确认房卡显示日期和场次但不阻挡当前场次。
4. 标记故障并提交文字证据，确认立即生效；提交恢复后确认仍不能开房。
5. 在后台查看恢复审核。提交人缺少 `review.self` 时不能自审；管理员或被授予该权限的审核人可自审并留下标记。
6. 库存、挂账回款、特殊差额、超额赠酒水、客诉恢复使用同一条件自审逻辑。

完整人工流程见根目录 `店员练习手册.md`，既有证据见 `验收清单.md`。

## 6. 常见问题

### 无法访问站点

先确认是否有监听：

```powershell
netstat -ano | Select-String ':4173'
```

- 没有 `LISTENING`：运行 `node server.js`。
- 有监听但页面是旧版本：记录 PID，使用 `Get-Process -Id <PID>` 确认它是本项目的 Node 服务，再停止并重启。
- 不要在未核对进程前停止未知 PID。

### `EADDRINUSE`

4173 已被其他进程占用。先用上面的 `netstat` 与 `Get-Process` 确认，停止旧服务后再启动；也可临时设置其他端口：

```powershell
$env:PORT = 4174
node server.js
```

### 页面数据和预期不同

- `/` 与 `/admin` 在同一来源下共享 `jbhh-demo-v1`。
- `localhost:4173` 与 `电脑局域网IP:4173` 是不同来源，数据不会共享。
- 可从“我的”恢复演示数据；这会清除业务练习数据，但不会清除主题偏好。

### 后台入口显示无权限

当前身份缺少 `backend.view`。切换管理员，或由管理员在身份权限中给目标身份开启“进入管理后台”。这只是演示权限，不是真实认证。
