# 需求与业务规则

`AGENTS.md` 是当前规则源；本文按领域整理，便于新会话快速定位。新需求与本文冲突时，以用户最新明确指示为准，并同步更新规则、测试和文档。

## 身份、入口与权限

| 身份 | 岗位说明 |
|---|---|
| 管理员 | 后台总管理 |
| 卓老板 | 老板 |
| 老板娘 | 店长 |
| 邵老板 | 大堂经理 |
| 雄老板 | 外联经理 |
| 卓益 | 订房服务专员 |
| 美娇 | 订房专员 |

- 岗位名称只作说明，实际操作以具体权限为准。
- 店员入口为 `/`；后台入口为 `/admin`，需要 `backend.view`。
- 管理员权限固定；管理员可调整其他身份的具体权限。
- 六类敏感审核为挂账回款、特殊差额、超额赠酒水、房间恢复、库存盘点、客诉／异常恢复。
- 审核六类申请必须先拥有对应审核权限。审核人与提交人相同时，还必须拥有 `review.self`；批准和驳回都记录提交人、审核人、时间、备注和自审授权标记。
- 故障／维护标记提交文字或照片后立即生效，不需要审核；只有恢复空房需要审核。

## 房间、时段和价格

- 固定 9 房，不存在 V04，不得自行规范化房号。
- 房型：V01/V02/V03 小房；V05/V06 中房；333/666/999 大房；888 VIP 房。
- 白天场：14:00–18:00，纯唱小／中房 68 元、大房 88 元、VIP 108 元。
- 夜间计价时段：18:00–次日 02:00。标准套餐基础房费和赠饮分账，总价按现有 `quote` 规则生成；不得重复收取赠饮。
- 已跨 02:00 的营业单可继续消费和结账；新单不能在关闭时段开房。

## 开房、酒水和其他消费

- 开房渠道默认线下，可选美团／抖音。平台券开房费用按 0 元计收并保留待接扫码验券信息；后续增购正常计价。
- 普通赠饮 12 支／打，高端赠饮 10 支／打；销售整打统一 12 支，半打 6 支且为整打价格一半。
- 开房赠饮不提供手工半打入口。
- 开房可选饮料、红青岛、蓝妹（罐装）和黑金百威。选择“饮料”时必须在开房表单配完实际种类和总支数。
- 加酒水类别为啤酒、饮料、汽水、瓶装水；啤酒类别包含普通和高端商品。饮料和汽水只按单支销售，瓶装水 2 元／支。
- 一张加单可以添加多种酒水。
- “加其他”支持小吃、热食、烧鸡烤肉、代驾和其他。代驾填写金额；其他填写项目和金额。
- 套餐、付费增购和已赠酒水都可按支 1:1 换酒；只允许同级或向下，允许部分换，原金额不变；瓶装水不可换出。
- 同一种可按打销售的酒水每增购 24 支可直接赠半打；超额部分进入赠酒水审核，赠送不增加应收，待确认会阻止结账和挂账。

## 收钱、结账与挂账

- “收钱”只收最近一笔未收增购；没有增购待收时收开房费用。收钱后房间继续营业。
- “结账”汇总所有剩余未收费用，完成后房间才转待清洁。
- 收钱与结账都支持微信、支付宝、现金、美团、抖音多笔付款，合计必须匹配。
- 结账少收默认记免零；选择特殊情况时必须写说明并进入差额审核。
- 所有演示身份都可从结账申请挂账；手机号或姓名至少一个，备注和经办签名必填。
- 挂账只包含尚未收取的余额。≤1000 元店长审批，>1000 元老板审批；提单起 24 小时到期，挂账不计实收。
- 回款先登记金额和方式，审核通过后才扣减欠款并计入实收。存酒不能抵欠款。

## 预订和房态

- 预订日期支持今天、明天、后天、第 N 天后；场次为下午 14:00–18:00、夜间 20:00–次日 02:00。
- 预订方式为线下、手机、座机、美团、抖音。
- 未来预订不占当前房态；营业中房间也可登记多个不冲突的未来场次。
- 到店开房只接管当前匹配场次。场次开始后未开房，每小时在页面提醒登记预订的员工。
- 有未来预订的空房卡显示“已预订”，仍可处理当前场次；提示只显示日期和场次。
- 故障／维护中以及待恢复审核的房间不能开房或预订。

## 存取酒、库存和消耗品

- 存酒联系人手机号或姓名至少一个；一次可添加多种酒。
- 搜索支持手机号任意部分或姓名；取酒用手机号最后 4–11 位或完整姓名核对。
- 存酒独立于欠款，不重复扣商品销售库存。
- 未建账商品只记录流水，不校验、不预警；期初盘点后开始管理，不追扣历史流水。
- 库存分为酒水支数和消耗品包／份数；消耗品单独记录已开封数量。
- 期初建账和每次盘点先形成申请，审核后才改变账面数量。

## 支出、采购、客诉和交班

- 所有演示岗位默认可登记支出／报销；低于财务的岗位只看本人，财务、店长、老板、管理员可看全部，仍受具体权限覆盖。
- 报销超过 500 元进入老板审批。性质包括一次性支出、固定支出、资金周转；付款方式沿用五种收款方式。
- 采购自动关联支出／报销记录，并保留经办归属。
- 客诉／异常记录包含日期、房号、类型、描述、负责人、处理结果和备注。未完成及待审核记录从每天 14:00 起在页面提示。
- 负责人提交处理结果后进入恢复审核，审核通过才转为完成。
- 交班填写实点收款合计和前台现金；前台现金仅留档，不重复计入实收差异。

## 报表和主题

- 报表按日／周／月切换，仅列当前统计期内开过房的房间。
- 房费单列；酒水消费含开房赠饮；后续赠送另列酒水、打数和赠送人；套餐赠饮不填赠送人。
- 美食散酒只统计付费美食及非整打／半打付费酒水；套餐免费果盘、小吃不计入。
- “我的”中选择日间、夜间、自动。自动模式以设备实际时间 06:00–19:00 为日间，其余为夜间，与练习时间无关。

## 演示边界

- 数据只在当前浏览器保存，localhost 与局域网 IP 属于不同来源，数据不会自动共享。
- 演示身份切换不等于真实登录认证。
- 页面提醒不等于手机推送或钉钉通知。
- 手工确认收款不等于银行到账或真实支付。
