# 金碧辉煌 KTV · 手机操作演示

这是一个面向 KTV 店员和管理人员的手机优先操作演示，用于核对开房、消费、收款、预订、存取酒、库存、审批与营业报表流程。当前项目是原生 HTML、CSS、JavaScript 和 Node 静态服务器，业务数据保存在当前浏览器；**不能作为正式营业系统使用**。

## 主要能力

- 店员端：房态、开房、增购、换酒、赠送、收钱、结账、挂账、预订和存取酒。
- “我的”：个人业务归属、页面配色、采购、支出／报销、客诉／异常、交班和练习设置。
- 后台端：员工补录、具体权限配置、库存、敏感业务审核和管理查询。
- 报表：按日／周／月汇总本机演示账单。
- 数据准备：`database/` 提供 PostgreSQL 16 关系型基线和历史报表导入映射；运行中的页面尚未连接数据库。
